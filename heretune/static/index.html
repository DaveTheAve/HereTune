Quick analysis presets

Start with a sensible profile, then customize anything below. Applying a preset changes the form only; nothing is written until you click Save settings.

01

Media library

Combine local disks, multiple content folders, NAS shares, and folders exposed by other computers into one library.

Media foldersEach folder is scanned independently. If one network share is offline, HereTune keeps the other roots available instead of marking the offline share's videos missing.

Local paths and UNC shares are supported.
Multi-root identityFiles are keyed by root + relative path, so Movies\clip.mp4 can safely exist on more than one computer or share.
02

Analysis engine

Auto prefers Hybrid: GPU for frame acquisition, CPU for the correction math.

03

Sampling

Quality versus analysis time. The shipped defaults are intentionally generous for 5.7K+ long-form VR.

04

Native image grade

Conservative bounds for white balance, regional tone, saturation, and detail. HereTune uses HereSphere’s native controls rather than baking changes into the video.

05

Per-channel color & sparse scenes

Use tiny RGB nonlinear trims for brightness-dependent color casts, then create as many stable grades as the movie genuinely needs. Camera cuts alone do not create grades.

06

VR framing & orientation

Measure packing, projection, persistent borders, eye order, and camera roll. Automatic HSP application is controlled separately in HereSphere & HSP policy.

07

Stereo, stitching & lens calibration

Measure eye mismatch, roll, scale, shear, stitch geometry, and fisheye/FOV evidence. These measurements stay diagnostic until enabled in the HSP output policy.

08

Audio & autofocus

Measure loudness, lip-sync/drift evidence, and conservative autofocus bounds from stereo depth. Native timing/autofocus output is controlled separately in HSP policy.

09

HereSphere & HSP policy

Control which measured corrections reach Auto HSPs, whether portable sidecars are exported, and which controls may be overridden for an individual video.

Auto HSP output controlsThese switches decide what reaches the player. Analysis evidence remains stored, so Save can rebuild existing HSPs without re-analyzing any movie.
